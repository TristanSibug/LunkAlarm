# Clock font

Inter variable Latin upright, from `@fontsource-variable/inter` version 5.3.0.
Source: https://www.npmjs.com/package/@fontsource-variable/inter
Font project: https://github.com/rsms/inter

The package was downloaded from the npm registry over HTTPS and verified against its published SHA-512 integrity before extraction. The font is hosted with the app; visitors do not need an external font service. Its SIL Open Font License is included in OFL.txt.

## Optional clock faces

These assets are bundled locally and loaded when their previews or clock face are used. The original font files are distributed unmodified; CSS aliases label them in the picker.

- **Rounded:** Quicksand variable upright, [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/quicksand). Original `Quicksand[wght].ttf`, saved as `quicksand-variable.ttf`; license: `Quicksand-OFL.txt`.
- **Monospace:** JetBrains Mono variable upright, [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/jetbrainsmono). Original `JetBrainsMono[wght].ttf`, saved as `jetbrains-mono-variable.ttf`; license: `JetBrainsMono-OFL.txt`.
- **Digital:** DSEG7 Classic Light from the [upstream DSEG v0.46 release](https://github.com/keshikan/DSEG/releases/tag/v0.46). Original `DSEG7Classic-Light.woff2`, saved as `dseg7-classic-light.woff2`; license: `DSEG-OFL.txt`.
- **Serif:** Georgia with system serif fallbacks; no system font file is redistributed.

Inter remains the default. The app makes no external font-service requests.
