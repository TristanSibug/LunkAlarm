# LunkAlarm 1.10.4 — Clock Fonts and Alarm Setup

This release brings the new About page and clock settings to both Android and iOS.

### What's new

- Swipe down from the big clock to open About and access Theme, Clock font, and Clock format.
- Preview and choose System Light, Rounded, Serif, or Monospaced. LunkAlarm saves your choice and keeps System Light as the default.
- See the current clock format at a glance with an example like `2:30 PM` or `14:30`.
- Use Smart Duplicate to create up to four copies at intervals of 1–59 minutes or 1–23 hours. Type the interval or use the stepper. Choose **Original only** to keep wake-up tests on the first alarm, or **All alarms** to queue a set for each alarm that rings.
- Set up alarm access on first launch. On iOS, LunkAlarm waits for the permission request to finish before refreshing alarms.

### Downloads

- **Android** · Install the attached `LunkAlarm-Android-1.10.4.apk` over your existing permanently signed installation to keep saved alarms.
- **iOS** · Sign and install the attached `LunkAlarm-iOS-1.10.4-unsigned.ipa` using your usual sideloading method.
- **Website** · [Open LunkAlarm in your browser](https://alarm.tjesibug.online).
